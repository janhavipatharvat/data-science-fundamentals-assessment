# Data Science Fundamentals Assessment

Internship Task 1: a structured Jupyter notebook covering the fundamentals of data science.

## What's inside

| Section | Topic |
|---|---|
| 1 | Data science lifecycle, types of analysis, industry use cases |
| 2 | Python basics: variables, operators, conditionals, loops, functions, lists, tuples, dictionaries, sets, file handling |
| 3 | Statistics: mean, median, mode, variance, standard deviation, percentiles, probability, correlation |
| 4 | Data types and structures: numerical, categorical, ordinal, datetime, text |
| 5 | Best practices: clean code, naming, documentation, reproducibility, responsible interpretation |
| 6 | Four practical assignments (Python, statistics from scratch, pandas data cleaning, analysis and visualisation) |

## How to run

```bash
pip install -r requirements.txt
jupyter notebook Data_Science_Fundamentals_Assessment.ipynb
```

Then choose **Kernel → Restart & Run All**. A fixed random seed (42) makes results reproducible.

## Files

- `Data_Science_Fundamentals_Assessment.ipynb`: the notebook, with outputs included
- `PROJECT_REPORT.md`: the project report
- `requirements.txt`: dependencies
